# sudokuGenerator

A small Tkinter Sudoku generator with buttons to reveal answers, animate the solution, and save the board as an image.

## Run

```powershell
python sudokuGenerator.py
```

Choose the subgrid size with `--n`:

```powershell
python sudokuGenerator.py --n 4
```

`--n 3` creates a standard 9x9 puzzle. `--n 4` creates a 16x16 puzzle.

## Requirements

- Python 3
- Pillow, for saving screenshots

Install Pillow with:

```powershell
pip install Pillow
```
